# City Traffic Violations Dashboard 🚦

An interactive Power BI dashboard analyzing city traffic violation data — built to surface patterns in fines, severity, location, and time to support data-driven traffic enforcement decisions.

## 📊 Overview

This dashboard provides a single-page view of city traffic violation trends, helping identify high-risk zones, peak violation periods, and revenue from fines.

## 🖥️ Dashboard Pages

- **City Traffic Violation** — main dashboard page with KPIs, trend charts, and filters
- **Summary** — supplementary summary page

## 📈 Key Metrics (Cards)

| Metric | Description |
|---|---|
| Total Violations | Total count of recorded traffic violations |
| Total Fine Amount | Sum of all fines collected |
| High Severity Rate | Percentage of violations classified as high severity |
| Accident Rate | Percentage of violations resulting in accidents |
| Avg Fine per Violation | Average fine amount per violation |

## 📉 Visuals

- **Area Chart** — Total Violations trend by Month
- **Column Chart** — Total Violations by Severity Level
- **Donut Chart** — Total Fine Amount distribution by Vehicle Type
- **Waterfall Chart** — Total Violations breakdown by Road Type
- **Slicers** — Filter by Day of Week, Location Zone, and Month-Year

## 🧰 Tools & Technologies

- **Power BI Desktop** — dashboard design and visualization
- **DAX** — calculated measures (Total Violations, Total Fine Amount, High Severity Rate, Accident Rate, Avg Fine per Violation)
- **Power Query** — data cleaning and transformation

## 🚀 How to Use

1. Clone or download this repository
2. Open `projectda.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
3. Explore the visuals and use the slicers (Day of Week, Location Zone, Month-Year) to filter the data
4. Watch the demo video above for a quick walkthrough
